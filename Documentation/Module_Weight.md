# 模块功能说明：体重追踪 (Weight Tracking)

体重追踪模块是一个专业的可视化健康监控工具，帮助用户直观地掌握爱宠的体重变化趋势。

### 1. 可视化图表 (Weight Chart)
- **核心展示**: 页面顶部是一个使用 Apple `Charts` 框架绘制的、平滑美观的体重历史折线图。
- **交互性**: 用户可以触摸并滑动图表，查看任意历史时间节点的具体体重数值。
- **目标线**: 如果用户设置了目标体重，图表中会额外绘制一条贯穿始终的“目标线”，让当前体重与目标的差距一目了然。

### 2. 数据摘要 (Data Summary)
图表下方是三张关键的数据摘要卡片，提供了即时的信息解读：
- **当前体重**: 显示最近一次记录的体重数值和记录日期。
- **体重变化**: 显示与上一次记录相比的体重变化量，并用清晰的升降箭头（`↑` 或 `↓`）表示变化方向。
- **体重目标**: 这是一个免费的引导性功能，用户可以为宠物设定一个理想的体重目标。设定后，卡片会动态显示当前体重与目标的差距。

### 3. 历史列表
页面底部是一个详细的体重历史记录列表，展示了每一次记录的日期和具体数值，用户可以点击任意一条进行编辑或删除。
