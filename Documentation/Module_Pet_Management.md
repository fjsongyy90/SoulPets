# 模块功能说明：宠物管理 (Pet Management)

宠物管理模块涵盖了从迎接新宠物到维护其终身档案的全部功能。

### 1. 添加新宠物 (Add New Pet)
这是一个引导式的、分为三步的清晰流程，旨在让添加过程充满仪式感：
- **步骤一：选择类型**
  - **UI**: 页面顶部有一个三段式进度指示器。主体是一个使用可爱插画图标的宠物类型网格。
  - **MVP 逻辑**: “猫 (Cat)”和“狗 (Dog)”图标全彩可点击。其他所有宠物图标（仓鼠、兔子等）均处理成灰色/半透明，并在图标下方或角落有一个小小的 `Soon` 标签。
  - **交互**: 点击灰色图标时，弹出一个提示：“我们正在努力工作中，很快就能支持更多小可爱了！”。“下一步”按钮在用户选择有效宠物类型前为禁用状态。
- **步骤二：填写核心信息**
  - **UI**: 进度指示器第二段高亮。表单包含一个大的圆形照片上传区域，以及多个输入字段。
  - **控件规格**:
    - `Name` (名字): `TextField`。
    - `Breed / Color` (品种 / 花色): `TextField`。
    - `Gender` (性别): 使用 `SegmentedControl` 提供 `Male`, `Female`, `Other` 选项。
    - `Neutered / Spayed?` (是否绝育?): 使用 `Toggle` 开关。
- **步骤三：设定重要日期**
  - **UI**: 进度指示器三段全部高亮。
  - **控件规格**:
    - `Birthday` (生日): 点击后弹出 iOS 原生的 `DatePicker`。
    - `Adoption Day / Gotcha Day` (领养日): 点击后弹出 `DatePicker`。
    - `Weight Unit` (体重单位): 使用 `SegmentedControl` 提供 `kg` 和 `lbs` 选项。
  - **情感化交互**:
    - “完成”按钮的文案需动态显示宠物名字，如: `Finish & Welcome Mimi!`。
    - 点击完成后，需弹出一个 `Alert`，询问用户是否要为宠物自动添加生日提醒。

### 2. 查看与编辑宠物档案 (View & Edit Profile)
- **查看模式**: 提供一个只读的、信息丰富的宠物档案页，以分组卡片的形式清晰展示所有信息。导航栏右侧有一个“Edit”按钮。
- **编辑模式**: 用户可以从查看模式进入编辑模式，对所有字段进行修改。导航栏左侧是“返回”按钮，当有未保存的修改时，点击返回会弹窗提示用户保存或放弃更改。
- **国际化字段**: 档案中包含了 `Microchip ID` 和 `Insurance Policy No.` 等符合海外用户习惯的字段。
- **删除操作**: 在编辑模式中，提供删除该宠物档案的选项，操作会要求用户二次确认。
