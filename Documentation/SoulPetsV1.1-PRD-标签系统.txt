SoulPets v1.1.0 PRD (产品需求文档) - 标签系统
1. v1.1.0 核心目标
•	1. 扩展宠物支持 (共10种)：在 v1.0 的 猫 (Cat) 和 狗 (Dog) 基础上，新增对8种新宠物的支持：
o	兔子 (Rabbit)
o	仓鼠 (Hamster)
o	豚鼠 (Guinea Pig)
o	鸟类 (Bird)
o	蜥蜴 (Lizard)
o	龟 (Tortoise)
o	鱼 (Fish)
o	蛇 (Snake)
•	2. 完善标签系统 (共60项)：
o	更新 v1.0 标签 (39项)：扩展现有标签的适用宠物范围（例如“生日”应适用于所有宠物）。
o	新增 v1.1.0 标签 (21项)：引入新标签以满足新宠物的专属记录需求。
2. 开发与数据迁移说明 (致开发者)
•	依赖 TagPresetService 幂等性：本次更新依赖 TagPresetService.swift 中的 syncPresetTags 逻辑。
•	v1.0 标签更新：syncPresetTags 函数会遍历所有 v1.0 标签 (如 planning.birthday)，当检测到代码中 associatedPetTypes 列表发生变化（例如从 [.cat, .dog] 变为 [.cat, .dog, .rabbit, ...]）时，它会自动更新 (UPDATE) 数据库中该条记录，而不会创建新标签。
•	v1.1.0 标签新增：当检测到数据库中不存在的 code 时 (如 daily.hay)，它会自动插入 (INSERT) 新标签。
•	结论：此方案可确保所有新老用户的标签库都能平滑升级到 v1.1.0 的最新标准，用户在 v1.0 创建的自定义排序、隐藏等设置均会保留。
