# 模块功能说明：标签管理 (Tag Management)

标签系统是 SoulPets 的核心，而标签管理功能则赋予用户个性化整理这个系统的能力，以实现最高效的记录和提醒体验。

### 1. 功能入口 (Entry Point)

- 用户可以在“创建记录”或“创建提醒”流程中，在选择标签的界面右上角找到“管理标签 (Manage Tags)”的入口。

### 2. 核心交互：按宠物类型管理

- 如果用户同时拥有多种类型的宠物（如猫和狗），进入管理界面后，系统会首先要求用户选择要管理哪种宠物的标签集（例如，一个列表显示“管理猫的标签”、“管理狗的标签”）。
- 如果用户只有一种类型的宠物，则直接进入该类型的标签管理主界面。

### 3. 管理界面与 MVP 功能详述

管理界面以分组列表的形式，展示所选宠物类型的所有预设标签。在 MVP（免费）版本中，用户可以进行以下操作：

- **[排序 (Sort)]**
  - **交互**: 每个标签的左侧都有一个可拖拽的排序手柄 `☰` 图标。
  - **功能**: 用户可以通过拖拽，自由调整每个分类内部的标签顺序，将最常用的项目排在最前面。

- **[配置提醒可用性 (Configure for Reminders)]**
  - **交互**: 每个标签的旁边都有一个开关（Toggle Switch）控件。
  - **功能**: 这个开关决定了该标签是否会出现在“创建提醒”的标签选择列表里。
  - **逻辑**:
    - **开启**: 标签会同时出现在“创建记录”和“创建提醒”的列表中。
    - **关闭**: 标签将仅从“创建提醒”的列表中隐藏，但在“创建记录”时依然可见。
  - **智能默认值**: 系统会为标签预设好开关状态。例如，“异常情况 (Abnormal Condition)”、“尿便 (Potty)”等纯记录性标签，该开关将默认关闭。

- **[隐藏/显示 (Hide/Show)]**
  - **交互**: 每个标签的最右侧都有一个“眼睛” `👁️` 图标。
  - **功能**: 用于将一个不常用的标签从所有选择列表（包括记录和提醒）中彻底隐藏，以简化界面。被隐藏的标签会在管理页中变暗并标记为“已隐藏”，用户可以随时再次点击“眼睛”图标将其恢复显示。

### 4. Pro 功能预告 (Pro Feature Teaser)

- 在整个标签列表的最底部，放置一个灰色、不可点击的按钮，文案为：“+ Add Custom Tag (Pro)”。
- **目的**:
  1.  **功能预告**: 让免费用户知道未来会有强大的“自定义标签”功能。
  2.  **需求验证**: 吸引有需要的用户向您反馈，验证这是一个有价值的付费点。
  3.  **无打扰体验**: 作为一个安静的占位符，它不会像横幅广告一样打扰 MVP 用户的免费体验。
