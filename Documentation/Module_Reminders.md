# 模块功能说明：智能提醒 (Reminders)

智能提醒模块是一个强大且富有情感关怀的日程管理中心，确保用户不会错过任何与爱宠相关的重要事项。

### 1. 提醒主页 (Main View)
- **结构化布局**: 页面顶部以醒目的卡片突出展示“今日待办”，让最重要的任务一目了然。下方则以紧凑列表的形式，按时间顺序展示所有未来的提醒。
- **状态筛选**: 用户可以轻松地在“待办 (Upcoming)”和“已完成 (Completed)”之间切换视图，方便回顾历史。
- **空状态设计**: 当所有任务都完成后，页面会显示治愈系的插画和文案，鼓励用户享受与爱宠的真实互动时光。

### 2. 创建与编辑提醒
- **灵活的重复规则**: 应用的核心优势之一。用户可以设置高度灵活的重复规则，如“每3周”、“每2个月”等，完全贴合真实的养宠需求。
- **基于标签**: 创建提醒时，用户从与“记录”功能一致的标签库中选择事件类型，降低了学习成本。

### 3. 高效的交互与闭环
- **快捷操作**: 在提醒列表和系统通知中，都提供了“标记为完成”和“稍后提醒”的快捷按钮，用户无需进入应用即可处理。
- **“提醒-记录”桥梁**: 当用户完成一个提醒（如“打疫苗”）后，系统会智能地弹窗询问是否要为此创建一条对应的历史记录，并能自动预填好大部分信息。这个功能将“计划”与“历史”无缝连接，构成了应用的核心体验闭环。

重复提醒的正确逻辑：
Reminder表：保存模板信息，startDate永不变更
ReminderCompletion表：记录每次完成的日期
显示逻辑：
needsReminderOn(date:) 基于原始startDate和重复规则计算
isCompletedOn(date:) 检查指定日期是否已完成
今天完成重复提醒后，立即在未来提醒中显示下一个周期
