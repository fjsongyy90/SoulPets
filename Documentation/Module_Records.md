# 模块功能说明：事件记录 (Records)

事件记录模块是 SoulPets 的核心功能之一，旨在为用户的爱宠构建一部完整的数字生命日志。

### 1. 记录时间线 (Timeline View)
- **视觉呈现**: 所有记录都以时间倒序的方式，呈现在一个垂直的、无限滚动的时间线上。
- **卡片式设计**: 每条记录都是一张独立的卡片，清晰地展示了事件的标签图标与名称、确切的日期时间、文字备注的预览，以及附加照片的缩略图。
- **强大的筛选与搜索**:
  - **宠物筛选**: 页面顶部提供一个 `SegmentedControl`，用于在“所有宠物”和“当前宠物”的记录之间切换。
  - **内容搜索**: 提供一个 `SearchBar`，允许用户按关键字（如“疫苗”、“驱虫”）或直接选择标签来快速过滤查找特定的历史事件。

### 2. 添加新记录 (Add New Record)
添加记录的流程被设计得智能且高效，在一个全屏模态窗口(Modal)中分两步完成：
- **第一步：选择宠物与事件**
  - **宠物选择**: 页面顶部是一个支持**多选**的、横向滚动的宠物头像列表。
  - **动态标签库**: 核心智能功能。下方的标签网格会根据上方选择的宠物类型组合**动态刷新**。例如，同时选择一只猫和一只狗时，网格**只显示**猫狗的**共同标签**。
  - **快捷访问**: 网格顶部会自动出现一个“最近使用 (Recently Used)”的分组，方便用户快速点选高频事件。
- **第二步：填写记录详情**
  - **上下文标题**: 页面标题会动态显示为上一步所选标签的名称（例如“Vaccine”）。
  - **表单字段**:
    - `Date & Time`: 一个可点击的区域，弹出 iOS 原生的日期和时间选择器，默认值为当前时刻。
    - `Memo/Notes`: 一个多行文本输入框。
    - `Photos`: 一个“+ Add Photos”按钮，允许用户添加照片附件。
    - `Cost`: (为未来记账功能预留) 一个可选的数字输入框。
